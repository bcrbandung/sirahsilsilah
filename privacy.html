Kebijakan Privasi

Sirah Silsilah · sirahsilsilah.my.id · Berlaku sejak 16 Oktober 2026

Tentang layanan ini

Sirah Silsilah adalah situs edukasi berisi silsilah keluarga Rasulullah ﷺ dan para sahabat beserta kisah sirah. Pengelola juga memakai aplikasi "Sirah Silsilah Publisher" untuk mengunggah konten edukasi ke akun media sosial resmi Sirah Silsilah sendiri (Instagram, Threads, dan TikTok).

Data yang kami kumpulkan

Situs ini tidak memiliki fitur pendaftaran, tidak meminta data pribadi pengunjung, dan tidak memasang iklan. Penyedia hosting (Vercel) dapat mencatat data teknis standar seperti alamat IP dan jenis browser untuk keamanan dan operasional server.

Integrasi media sosial

Aplikasi Sirah Silsilah Publisher hanya terhubung ke akun milik pengelola sendiri. Izin yang dipakai terbatas pada membaca informasi dasar akun (nama pengguna dan ID) serta mengunggah konten ke akun tersebut. Token akses disimpan secara lokal di perangkat pengelola, tidak dibagikan ke pihak lain, dan tidak dipakai untuk mengakses akun pengguna lain.

Penghapusan data

Pengelola dapat mencabut akses aplikasi kapan saja dari pengaturan akun Instagram, Threads, atau TikTok. Setelah dicabut, token lokal dihapus. Untuk pertanyaan atau permintaan penghapusan data, hubungi kami melalui pesan langsung di akun Instagram @sirahsilsilah.my.id.

Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu tersedia di halaman ini.
