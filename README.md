# Sirah Silsilah

Silsilah keluarga Rasulullah ﷺ dan para sahabat: diagram keluarga interaktif (2 generasi ke atas dan ke bawah), pencari hubungan kekerabatan, pohon nasab Quraisy, dan 55 kisah sirah dengan sumbernya.

Situs: https://sirahsilsilah.vercel.app

Satu file statis (`index.html`), tanpa build. Data tokoh, pernikahan, dan kisah ada di dalam blok `// DATA START` … `// DATA END`.

Rujukan: Sirah Ibnu Hisyam, Thabaqat Ibnu Sa'd, al-Isti'ab, Usdul Ghabah, al-Ishabah, Siyar A'lam an-Nubala'. Disusun dengan bantuan AI; cocokkan dengan kitab rujukan sebelum mengutip.

Deploy: `vercel deploy --prod` dari folder ini (proyek Vercel `da-paragon/sirahsilsilah`).
